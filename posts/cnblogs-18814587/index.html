idea插件开发踩坑记录

问题

build.gradles.kts配置文件中全部爆红，提示Cannot access script base class ‘org.gradle.kotlin.dsl.KotlinBuildScript’

  1. 删除C:\Users<you>\AppData\Local\JetBrains\IntelliJIdea2021.1\caches（如果遇到提示文件正在被使用，关闭idea再删除就可以了）。
  2. 重启idea。
  3. 点击Load Script Configurations，或等idea自动加载脚本配置。

启动后插件没生效，控制台报错Caused by: java.lang.ClassNotFoundException找不到: my/class.name.Here PluginClassLoader[xxx]

  1. 插件项目默认在src/main下创建了kotlin目录，如果把java文件放在Kotlin的文件夹下就会出现这个问题！！！
  2. 在src/main下新建java目录，把java的文件移过去就可以解决。


这两个问题都是在stackoverflow找到的解决方案，后续持续更新插件开发中遇到的问题。
